Schnellstartanleitung

Einrichtungs- & Verbindungsanleitung

Verbinde BugAgent AI in unter 2 Minuten mit deinem Atlassian-Jira-Workspace und deinen bevorzugten KI-Engines.

Jira Cloud & Server/Data Center verbinden

  1. Öffne das Seitenpanel der Erweiterung und navigiere zu Settings (Einstellungen) → Jira Connection.
  2. Gib die URL deiner Jira-Instanz ein (z. B. https://deine-firma.atlassian.net oder deine eigene Domain).
  3. Für Jira Cloud: Gib deine Atlassian-Konto-E-Mail und ein unter id.atlassian.com erstelltes API-Token ein.
    Für Server/Data Center: Wähle Personal Access Token (PAT) und füge dein Token ein.
  4. Klicke auf Test Jira Connection. Nach erfolgreicher Bestätigung klicke auf Save Settings.

Google Gemini API-Key abrufen

  1. Besuche Google AI Studio (aistudio.google.com) und melde dich mit deinem Google-Konto an.
  2. Klicke auf Create API key, wähle ein Google-Cloud-Projekt und kopiere den generierten Schlüssel.
  3. Füge den Schlüssel in den Einstellungen unter Gemini Vision Key ein und klicke auf Save Settings.

OpenAI API-Key abrufen (GPT-4o & GPT-4o-mini)

  1. Besuche die OpenAI Developer Platform (platform.openai.com) und melde dich an.
  2. Klicke auf Create new secret key, vergib eine Bezeichnung (z. B. BugAgent AI) und klicke auf Create secret key.
  3. Kopiere den Schlüssel (beginnt mit sk-...), füge ihn in Settings → OpenAI Vision Key ein und klicke auf Save Settings.
