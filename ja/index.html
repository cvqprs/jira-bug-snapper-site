主な機能と特徴

現代のQAチームとソフトウェアテスターのために構築

UIのリグレッションやソフトウェアの不具合をシームレスにキャプチャ、解析、注釈付け、報告するために必要なすべてが揃っています。

ワンクリックキャプチャとグローバルショートカット

表示中のタブをワンクリックで即座にキャプチャ。またはグローバルキーボードショートカット：⌘+Shift+S（macOS）および Alt+Shift+S（Win/Linux）を利用可能。クリップボードからの貼り付け（Ctrl+V / Cmd+V）にも対応。

デュアル Vision AI エンジン（Gemini & OpenAI）

高速な応答性を誇る Google Gemini（3.8 Flash）と、高度なUI解析を行う OpenAI（GPT-4o & GPT-4o-mini）を瞬時に切り替え。根本原因の仮説、再現手順、期待される結果を6言語で自動生成します。

Jira向け動作環境スペックの自動検出

OS、ブラウザのバージョン、ビューポート解像度、Retinaスケーリング比率を自動抽出し、手入力不要で美しいJira Wiki形式のテーブルとして整形します。

完全なダークモードと洗練されたUI

長時間のQAテストセッションでも目に優しい設計。ヘッダーの専用トグルで、明るいライトモードとバッテリー消費を抑えるダークモードをワンタッチで切り替えられます。

内蔵アノテーションとGDPR準拠ぼかし機能

Jiraに送信する前に、スクリーンショット上に矩形、矢印、テキスト注釈を描画したり、顧客の機密データ（個人情報、トークン、メールアドレス）を直接ぼかすことができます。

100% BYOK & テレメトリゼロのプライバシー設計

ユーザー自身のAPIキーを使用（BYOK）。すべてのJira認証情報、OpenAIキー、Geminiトークンは、ブラウザ内の chrome.storage.local に安全に暗号化保存され、外部へ送信されません。

接続・初期設定ガイド

以下の簡単な手順に従って、BugAgent AI を Atlassian Jira ワークスペースおよび AI エンジンに2分以内に接続できます。

Jira Cloud および Server/Data Center への接続手順

  1. 拡張機能のサイドパネルを開き、Settings（設定） → Jira Connection に移動します。
  2. Jira インスタンスのURL（例: https://your-company.atlassian.net またはカスタムドメイン）を入力します。
  3. Jira Cloudの場合: Atlassianアカウントのメールアドレスと、id.atlassian.com で発行した APIトークン を入力します。
    Server/Data Centerの場合: Personal Access Token (PAT) を選択してトークンを貼り付けます。
  4. Test Jira Connection をクリックし、接続確認後に Save Settings をクリックします。

Google Gemini API キーの取得手順

  1. Google AI Studio (aistudio.google.com) にアクセスし、Googleアカウントでログインします。
  2. Create API key をクリックし、Google Cloudプロジェクトを選択して、生成されたキーをコピーします。
  3. 拡張機能の設定画面の Gemini Vision Key に貼り付け、Save Settings をクリックします。

OpenAI API キーの取得手順 (GPT-4o & GPT-4o-mini)

  1. OpenAI Developer Platform (platform.openai.com) にアクセスしてログインします。
  2. Create new secret key をクリックし、識別名（例: BugAgent AI）を入力して Create secret key をクリックします。
  3. キー（sk-... で始まる文字列）をコピーし、設定画面の OpenAI Vision Key に貼り付けて Save Settings をクリックします。
