Quick Setup & Support

Get up and running in less than 2 minutes. Need assistance? We're here to help.

How to configure your Jira Connection

  1. Jira Server / Data Center (PAT): Open Jira → click your profile avatar → select Profile → click Personal Access Tokens → click Create token. In the extension Settings, choose Personal Access Token (PAT), paste your token, and click Test Jira Connection.
  2. Jira Cloud (*.atlassian.net): Visit your Atlassian API Tokens page → click Create API token. In Settings, select Basic Auth, enter your Atlassian Email and token, then save.

How to get your free Google Gemini API Key

  1. Visit Google AI Studio (aistudio.google.com) and sign in with your Google account.
  2. Click Get API key → Create API key.
  3. Copy your key (starts with AIzaSy...), paste it into Settings → Google Gemini API Key, and click Save Settings.
